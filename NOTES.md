# Project Notes: HoverSlam

## Overview
- Goal: Train an RL agent to perform a precise hoverslam landing maneuver under 2D planar physics.
- Baseline 1: Classical PID controller.
- Baseline 2: Standard PPO agent.
- Robust agent: Domain-randomized PPO agent (varying mass, wind, thrust limits, initial states).
